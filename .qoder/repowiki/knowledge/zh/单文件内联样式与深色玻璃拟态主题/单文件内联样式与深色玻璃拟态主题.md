本仓库的前端仅包含一个静态页面 src/web/index.html，采用纯 HTML + 内嵌 style + 原生 JavaScript 的零依赖方案，未引入任何 CSS 框架、组件库或构建工具。整体视觉风格为现代深色主题加玻璃拟态效果，通过 CSS 自定义属性集中管理设计令牌，形成统一的视觉语言。

系统与方法：无外部样式依赖，不依赖 Tailwind、Bootstrap、Ant Design 等第三方样式库或预处理器；CSS 自定义属性作为全局设计令牌；所有样式写在单个 style 块中按功能区域分段注释；使用媒体查询做移动端适配。

关键文件：src/web/index.html — 唯一前端入口，包含全部 HTML 结构、CSS 样式和交互逻辑。

架构与约定：在 :root 中集中定义背景色、文本色、强调色、语义色、圆角、阴影、过渡等变量作为设计令牌；大量使用 backdrop-filter 加半透明背景加细边框实现毛玻璃面板；统一使用 cubic-bezier(0.4, 0, 0.2, 1) 缓动和 slideUp 入场动画；以功能域前缀组织类名如 sidebar-*、msg.*、thinking-card、score-card、eval-panel、toast-card、splash-* 等；通过 dot.ok/warn.err.loading 配合 CSS 动画表示后端服务状态。

开发者应遵循的规则：新增样式时优先复用现有 CSS 变量不要硬编码颜色值；将新样式插入到对应功能区域的注释段内；保持深色主题一致性基于 bg-* text-* glass-border 等变量派生配色；避免引入外部 CSS 文件继续追加到 style 块中；按钮 hover 使用 rgba(255,255,255,0.08) 加 border-color: rgba(255,255,255,0.2)；加载态使用 --text-muted 点阵动画；新增布局需考虑 max-width: 768px 断点下的表现。
