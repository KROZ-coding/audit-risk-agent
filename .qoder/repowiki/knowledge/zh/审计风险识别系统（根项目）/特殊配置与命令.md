Windows 一键流程：双击 `前置库安装.bat` → 双击 `启动.bat`（默认端口 5000）；开发者手动：`uv sync` → 复制 `.env.example` 为 `.env` 填入 DeepSeek API Key → `uv run python src/main.py -m http -p 5000`；Docker 部署：`docker build -t audit-ai . && docker run -p 5000:5000 audit-ai`；评估：`uv run python tests/evaluation_report.py --mode tool|agent`。
