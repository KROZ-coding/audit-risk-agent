- LLM 行为约束（模型名、温度、系统提示词、工具清单）统一收敛于 `config/agent_llm_config.json`，代码侧只读不硬编码。
- 所有对外暴露的密钥与路径通过 `.env` 注入，`start.ps1` 在进程级设置环境变量后再启动主程序，禁止在源码中写死敏感信息。
- Python 依赖通过 `pyproject.toml` + `uv.lock` 双文件锁定，Docker 构建使用 `--frozen` 保证镜像与开发环境一致。
- 中文渲染依赖 `assets/wqy-microhei.ttc` 字体，PDF 与 matplotlib 图表均显式指定该字体路径以避免乱码。
- 测试脚本同时覆盖单元测试（pytest）与端到端评估（`evaluation_report.py`），评估结果统一写入 `tests/evaluation_results.json`。
