根目录为可独立部署的 Python 包 `audit-risk-agent`（v3.0），以 FastAPI + LangGraph ReAct Agent 为核心：
- 依赖与构建：`pyproject.toml` 声明全部运行时依赖，`uv.lock` 锁定版本；`Dockerfile` 基于 `python:3.12-slim`，通过 `uv sync --frozen --no-dev` 安装依赖并预下载 `all-MiniLM-L6-v2` 嵌入模型。
- 启动编排：Windows 侧由 `start.ps1` 统一负责 Python/uv 环境探测、`.env` 加载、知识库检查、再调用 `src/main.py -m http|flow|node`；`启动.bat` 仅做 BOM 修复后转发到 PowerShell。
- 配置边界：`config/agent_llm_config.json` 集中存放 LLM 参数、系统提示词（含思维链推理模板、五大风险维度判定表、JSON 输出 schema）以及工具清单，Agent 在运行时读取该文件驱动工具调用顺序。
- 数据层：`knowledge_base/` 内嵌审计准则、信披规则与典型案例 txt 作为本地 TF-IDF 知识库；`assets/` 提供中文字体 `wqy-microhei.ttc`、行业基准 `industry_benchmarks.json` 及图表资源。
- 测试与评估：`tests/` 包含财务计算器与数据校验器的单元测试，以及 `evaluation_report.py` 支持 tool/agent 两种量化评估模式，结果落盘 `evaluation_results.json`。
- 外部入口：`.env.example` 定义 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`COZE_WORKSPACE_PATH`、`LOG_LEVEL`、`ENV` 等环境变量，`start.ps1` 强制覆写 `COZE_WORKSPACE_PATH` 指向当前项目目录。
