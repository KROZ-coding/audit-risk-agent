【一句话】
  双击「前置库安装.bat」，按提示填一次 API Key，就能自动装好并打开系统。


【运行环境】
  - 系统：Windows 10 / 11
  - 需要：Python 3.10 或更高版本（本包已自带安装包，无需联网下载）
  - 需要：能联网（首次要下载 Python 依赖）
  - 一个 DeepSeek API Key（在 https://platform.deepseek.com/ 免费注册获取）


【没有 Python 环境？直接装自带的两个安装包】
  本包已自带下面两个安装包，新电脑/无环境时直接装它们即可：
  1) python-3.12.10-amd64.exe
       双击安装，务必勾选“Add python.exe to PATH”（添加到环境变量）
  2) VC_redist.x64.exe
       双击安装（Microsoft Visual C++ 运行库，部分依赖需要）
  装完这两个后，再双击“前置库安装.bat”即可。
  （若系统已有 Python 3.10+ 与 VC 运行库，可跳过本步；前置库安装.bat 也会自动检测并调用它们）


【最简单的启动方式（推荐）】
  1) 解压本压缩包，得到 audit-ai_v5.3GA_src 文件夹
  2) 双击文件夹里的「前置库安装.bat」
  3) 脚本会自动：检查 Python、安装 uv、创建配置文件、同步依赖
  4) 中途会弹出记事本让你填 API Key：
       找到 OPENAI_API_KEY= 这一行
       把等号右边改成你自己的 Key（以 sk- 开头）
       按 Ctrl+S 保存并关闭记事本
  5) 依赖装完后服务自动启动，浏览器会自动打开
       访问地址：http://localhost:5000
  6) 以后再次启动，双击「启动.bat」即可（无需重新装依赖）


【手动启动方式（给熟悉命令行的人）】
  1) 复制 .env.example 为 .env，填入你的 OPENAI_API_KEY
  2) 命令行进入项目目录，依次执行：
       uv sync
       uv run python scripts/init_knowledge_base.py   （首次构建知识库向量库）
       uv run python src/main.py -m http -p 5000
  3) 浏览器访问 http://localhost:5000


【重要提示】
  - 本包不含 API Key：你必须填自己的 Key，用别人的无法运行。
  - 首次启动较慢：要下载依赖 + 构建知识库向量库，请耐心等待。
  - 如果卡在依赖下载：多为网络问题，校园网/公司网可尝试切换网络。
  - PowerShell 提示无法运行脚本：用「前置库安装.bat」启动即可，它已处理好。


【项目结构速览】
  src/            核心源码（Agent、16 个分析工具、存储、前端）
  config/         Agent 系统提示词与工具配置
  knowledge_base/ 审计法规与案例语料（检索数据源）
  tests/          865 个单元测试（当前回归基线）
  docs/ *.html    项目文档、方案书大纲、演示视频脚本、答辩速查


【停止服务】
  在启动窗口按 Ctrl+C，或双击「stop.ps1」。
