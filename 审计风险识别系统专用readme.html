📦 阶段一：基础环境安装（仅首次）

以下组件仅需安装一次，后续启动直接进入阶段二。

  1. 安装 Visual C++ 运行时：双击 VC_redist.x64.exe，按向导完成安装。 （已安装可跳过）
  2. 安装 Python 3.12：双击 python-3.12.10-amd64.exe。
    ⚠️ 重要提醒：安装界面第一页，必须勾选底部的 "Add python.exe to PATH"！
    如遗漏此步骤，后续所有命令将无法识别 Python，需重新安装。
    勾选后点击 "Install Now" 完成安装。

⚙️ 阶段二：一键部署（核心步骤）

STEP ① 获取 API Key

前往 DeepSeek 开放平台 注册并获取 API Key（以 sk- 开头），复制备用。

💡 API Key 是调用 AI 模型的核心凭证，没有它系统将无法运行。

STEP ② 运行前置安装脚本

找到项目根目录下的 前置库安装.bat，双击运行。脚本将自动完成：

  1. ✅ 检测 Python 3.12 环境
  2. ✅ 自动安装 uv 包管理器（比 pip 快约 10 倍）
  3. ✅ 创建虚拟环境并下载全部依赖（首次约 1~3 分钟）
  4. ✅ 检查知识库文件就绪状态
📝 首次运行 · API Key 配置：
首次启动时会自动弹出记事本编辑 .env 配置文件：
1. 找到 OPENAI_API_KEY=... 这一行。
2. 将等号右侧替换为您的真实 API Key。
3. Ctrl+S 保存并关闭。
4. 回到命令行窗口，按任意键继续。
🎉 部署完成！ 浏览器将自动打开 http://localhost:5000。
系统控制台包含：多智能体辩论、向量检索、思维链推理、效果评估面板等全部功能。

🚀 阶段三：日常启动

首次部署完成后，每次使用只需：

双击 启动.bat，等待浏览器自动弹出即可。
💡 进阶用法（命令行）：在项目目录空白处右键 → "在终端中打开"，执行： 
# 快速启动（跳过依赖同步检查）
.\start.ps1 -SkipSync

# 指定自定义端口
.\start.ps1 -SkipSync -Port 8080

# 完整启动（含依赖检查）
.\start.ps1

🛠️ 常见问题排查

❓ 未检测到 Python 3.12+
解决方案：返回阶段一，重新安装 Python，务必勾选 Add to PATH。完成后重新双击 前置库安装.bat。
❓ uv 安装后无法识别
解决方案：关闭当前命令行窗口，重新双击 前置库安装.bat。
❓ Network Error / API 调用失败
解决方案：用记事本打开 .env，检查 OPENAI_API_KEY 是否为真实密钥（模板值 sk-your-xxx 无效）。同时确认账户余额充足。
❓ DLL load failed / 可视化模块异常
解决方案：返回阶段一重新安装 VC_redist.x64.exe，安装后重启计算机。
❓ 端口 5000 已被占用
解决方案：终端执行 .\start.ps1 -SkipSync -Port 8080，通过 http://localhost:8080 访问。
❓ 知识库检索无结果
解决方案：确认 knowledge_base/ 目录下存在法规 txt 文件。首次检索时会自动构建 ChromaDB 向量索引（约 5~10 秒）。
