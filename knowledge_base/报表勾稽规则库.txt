报表勾稽规则库

本库列出三大报表之间以及报表内部的核心勾稽关系，用于校验年报数据的内在一致性。任一勾稽关系不成立，均构成数据可靠性疑问，需要进一步核查。

一、资产负债表内部勾稽

1. 会计恒等式（最高优先级）
资产总计 = 负债总计 + 所有者权益总计
容差：因四舍五入允许千分之一以内偏差；超出即视为勾稽不平。

2. 流动资产合计 = 货币资金 + 交易性金融资产 + 应收票据 + 应收账款 + 预付款项 + 其他应收款 + 存货 + 合同资产 + 一年内到期的非流动资产 + 其他流动资产

3. 资产总计 = 流动资产合计 + 非流动资产合计

4. 所有者权益合计 = 实收资本(股本) + 资本公积 + 减:库存股 + 其他综合收益 + 专项储备 + 盈余公积 + 未分配利润 + 少数股东权益

二、利润表内部勾稽

1. 营业利润 = 营业收入 - 营业成本 - 税金及附加 - 销售费用 - 管理费用 - 研发费用 - 财务费用 - 资产减值损失 - 信用减值损失 + 其他收益 + 投资收益 + 公允价值变动收益 + 资产处置收益

2. 利润总额 = 营业利润 + 营业外收入 - 营业外支出

3. 净利润 = 利润总额 - 所得税费用

4. 净利润 = 归属于母公司股东的净利润 + 少数股东损益

5. 毛利 = 营业收入 - 营业成本；毛利率 = 毛利 / 营业收入

三、跨表勾稽（核心风险识别点）

1. 净利润 → 现金流量表起点
现金流量表补充资料中，"净利润"应等于利润表的净利润。间接法调整后应等于经营活动现金流量净额。
风险含义：若两表净利润不一致，指向报表编制错误或数据造假。

2. 未分配利润变动 ↔ 净利润与分红
本期末未分配利润 = 上期末未分配利润 + 本期归母净利润 - 本期提取盈余公积 - 本期宣告分配的股利
风险含义：差额无法解释时，可能存在利润虚增或权益科目调节。

3. 营业收入 ↔ 应收账款
应收账款增速显著高于营业收入增速（超出 20 个百分点）时，指向放宽信用政策冲收入或虚增收入嫌疑。
配套校验：销售商品收到的现金 / 营业收入 应大致稳定；该比率显著下降说明收入含金量恶化。

4. 营业收入 ↔ 销售商品提供劳务收到的现金
正常情况下，销售商品收到的现金 ≈ 营业收入 ×(1 + 增值税率) × 收现比例。
风险含义：比率长期低于 0.8 或逐年下降，指向收入真实性风险或回款能力恶化。

5. 营业成本 ↔ 存货与应付账款
购买商品接受劳务支付的现金 ≈ 营业成本 + 存货增加额 - 应付账款增加额
风险含义：差异过大指向成本结转异常或采购业务真实性问题。

6. 固定资产 ↔ 折旧
本期折旧额应与固定资产原值和折旧政策匹配。折旧额/固定资产原值 出现明显下降而无政策变更说明时，指向通过延长折旧年限调节利润。
配套校验：现金流量表"购建固定资产、无形资产和其他长期资产支付的现金"应与资产负债表固定资产及在建工程的增加额大致匹配。

7. 货币资金 ↔ 利息收入
利息收入 / 平均货币资金 应接近同期存款利率水平。
风险含义：货币资金余额巨大但利息收入极低，指向货币资金真实性问题（存贷双高的典型特征）。

8. 有息负债 ↔ 财务费用
财务费用中的利息支出 / 平均有息负债 应接近市场融资成本。
风险含义：偏离过大指向未披露的表外负债或资金占用。

9. 所得税费用 ↔ 利润总额
所得税费用 / 利润总额 应接近适用税率（考虑税收优惠与递延所得税后）。
风险含义：有效税率异常偏低且无优惠政策支撑，指向利润虚增（虚增的利润通常不交税）。

10. 现金流量表三项净额 ↔ 货币资金变动
经营活动现金流量净额 + 投资活动现金流量净额 + 筹资活动现金流量净额 + 汇率变动影响 = 现金及现金等价物净增加额
期末现金及现金等价物余额 - 期初余额 = 现金及现金等价物净增加额
风险含义：不成立即为编制错误。

四、盈利质量勾稽（利润与现金的背离）

1. 经营活动现金流量净额 / 净利润（现金含量比率）
健康区间：长期均值应大于 1。连续两期低于 0.5，指向利润未转化为现金，存在盈利质量问题。

2. 总应计利润 =（净利润 - 经营活动现金流量净额）/ 总资产
风险含义：数值持续偏高说明利润主要来自应计项目而非现金，是盈余操纵的核心特征（对应 Beneish M-Score 的 TATA 因子）。

五、多期趋势勾稽

1. 收入、利润、现金流三者的增长趋势应大致同向。出现"收入增、利润增、现金流降"的剪刀差，须重点核查。
2. 毛利率显著高于同行业且长期稳定异常，须核查成本归集与收入确认真实性。
3. 资产规模快速扩张但营业收入未同步增长，指向资产虚增或投资效率低下。

六、勾稽校验的输出规范

每项校验须输出：校验名称、左式取值、右式取值、差额、差额占比、是否通过、不通过时的风险指向。任一核心勾稽（会计恒等式、现金流量表净额与货币资金变动、净利润跨表一致）不通过时，应在报告中显著提示"财务数据内在一致性存在疑问，后续分析结论的可靠性受限"。
