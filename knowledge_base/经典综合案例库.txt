经典综合案例库

本库收录完整的年报风险识别案例，每个案例按"异常发现 → 交叉验证 → 定性判断 → 监管处罚"的全链路呈现，供综合研判环节参照，学习如何从财务信号推导到风险结论。

案例一：康得新（002450）虚增收入与货币资金造假

第一步 异常发现
1. 货币资金异常：账面货币资金常年超过 100 亿元，但同时存在大额有息负债并支付高额利息，形成典型"存贷双高"。
2. 利息收入与货币资金不匹配：巨额货币资金对应的利息收入极低，与市场存款利率严重背离。
3. 毛利率异常：预涂膜等主营产品毛利率显著高于同行业可比公司，且长期稳定异常。
4. 经营现金流与净利润背离：账面持续高盈利，但现金流质量与利润规模不匹配。

第二步 交叉验证
1. 货币资金真实性存疑（利息收入倒推）与债务规模扩张（需持续融资）形成矛盾：若真有百亿现金，为何仍高息举债。
2. 高毛利率与高应收账款并存，指向收入真实性问题。
3. 大股东股权高比例质押，存在资金占用动机。
4. 审计机构对货币资金函证程序的执行情况成为关注焦点。

第三步 定性判断
形成结论：存在虚增营业收入与货币资金被控股股东非经营性占用的重大风险嫌疑。核心逻辑链为"存贷双高 + 利息收入不匹配 + 高毛利率不可持续 + 大股东资金需求"。

第四步 监管处罚
证监会调查认定公司通过虚构销售业务虚增营业收入与利润，且货币资金实际被控股股东集中管理占用。公司被处以行政处罚，相关责任人被采取市场禁入措施，公司最终退市。

启示：存贷双高是货币资金造假的最强单一信号；应始终用"利息收入 / 平均货币资金"反算货币资金真实性。

案例二：康美药业（600518）财务数据系统性造假

第一步 异常发现
1. 货币资金规模巨大且逐年攀升，同时短期借款持续增加。
2. 存货规模异常庞大（中药材存货），且存货周转率显著低于同业。
3. 经营活动现金流与净利润长期背离。
4. 应收账款与营业收入的增长不匹配。

第二步 交叉验证
1. 中药材存货的实物盘点难以验证（与农林牧渔业的生物资产计量主观性类似），成为造假掩体。
2. 巨额货币资金与持续融资需求矛盾（存贷双高特征再现）。
3. 关联方资金往来规模异常。
4. 会计师事务所的存货监盘与货币资金函证程序有效性受质疑。

第三步 定性判断
形成结论：存在虚增货币资金、虚增营业收入与利润、未披露关联方资金占用的重大风险嫌疑。

第四步 监管处罚
证监会认定公司存在虚增货币资金、虚增收入及利润、隐瞒关联交易等违法事实，对公司及相关责任人作出行政处罚，负责审计的会计师事务所亦被处罚。该案成为证券集体诉讼的标志性案件。

启示：难以盘点的存货（中药材、生物资产、库存商品分散存放）叠加存贷双高，是财务造假的高危组合。

案例三：乐视网（300104）关联方资金占用与持续经营危机

第一步 异常发现
1. 应收账款激增，且大量应收来自关联方（乐视非上市体系）。
2. 经营活动现金流长期为负，依赖持续融资维持运转。
3. 关联交易金额巨大且占比高。
4. 商誉与无形资产（版权）规模大，减值风险高。

第二步 交叉验证
1. 关联销售占比高 + 关联应收账款账龄长且回款慢 → 收入真实性与资金占用双重嫌疑。
2. 经营现金流为负 + 筹资现金流为正 → 典型的"融资输血维持经营"模式，不可持续。
3. 大股东股权质押比例高，资金链紧张。
4. 版权类无形资产摊销与减值判断主观性强。

第三步 定性判断
形成结论：存在关联方非经营性资金占用、收入质量低下、持续经营存在重大不确定性的重大风险嫌疑。

第四步 监管处罚
公司因信息披露违法违规被处罚，控股股东资金占用问题被认定，公司连年亏损后退市。

启示：关联方应收账款是资金占用的常见通道；"经营现金流为负 + 筹资现金流为正"持续多年，即为持续经营红灯。

案例四：天神娱乐（002354）商誉暴雷

第一步 异常发现
1. 连续多年频繁并购，商誉规模占净资产比例极高（超过 50%）。
2. 并购标的业绩承诺完成率下降。
3. 商誉长期未计提减值。
4. 净利润高度依赖并购标的贡献。

第二步 交叉验证
1. 商誉占净资产比例过高 + 标的业绩承诺未达标 → 减值风险已实质发生但未反映。
2. 减值测试关键假设（收入增长率、折现率）与标的实际经营情况背离。
3. 文化传媒行业受政策与市场环境影响大，标的盈利可持续性弱。
4. 审计报告将商誉减值测试列为关键审计事项，说明注册会计师已识别该高风险领域。

第三步 定性判断
形成结论：存在商誉减值计提不充分、资产虚高的重大风险嫌疑，一旦集中计提将导致巨额亏损。

第四步 结果
公司在后续年度集中计提巨额商誉减值，当年净利润大幅亏损，股价大幅下跌，公司被实施风险警示。

启示：商誉/净资产 > 30% 且业绩承诺未达标而未减值，是商誉暴雷的前置信号；关键审计事项提及商誉减值即为强预警。

案例五：健康公司对照 —— 贵州茅台（600519）

第一步 指标表现
1. 毛利率长期稳定在 90% 以上，显著高于行业但由品牌溢价与定价权支撑，商业逻辑可验证。
2. 经营活动现金流量净额长期高于净利润，现金含量比率大于 1。
3. 资产负债率极低，货币资金充裕且无大额有息负债（无存贷双高特征）。
4. 应收账款极少（先款后货的销售模式），预收账款（合同负债）规模大。

第二步 交叉验证
1. 高毛利率 + 高现金含量 + 低应收 → 三者相互印证，盈利质量真实。
2. 无有息负债 + 高货币资金 → 不存在存贷双高矛盾。
3. 审计意见为标准无保留意见，无关键审计事项指向财务信息质量。

第三步 定性判断
形成结论：未发现重大风险嫌疑。高毛利率虽偏离行业基准但有充分商业逻辑支撑，属正常。

启示：指标偏离基准不等于风险。判断的关键是偏离是否有可验证的商业逻辑支撑，以及是否有多个信号相互矛盾。健康公司的特征是各项信号相互印证而非相互冲突。

综合启示：全链路研判的方法论

1. 单一异常只是线索，必须寻找第二、第三个独立信号交叉印证。
2. 最有价值的信号是"矛盾"：账面数据之间无法同时成立的组合（存贷双高、高利润低现金、账龄恶化却少计提坏账、高毛利却高应收）。
3. 审计意见与关键审计事项是注册会计师给出的风险指引，应优先关注其指向的领域。
4. 定性判断必须落到"风险嫌疑"层面，并给出具体的核查建议，而非直接结论。
5. 同时要能识别健康公司：偏离基准但商业逻辑成立、各信号相互印证的情况，不应误报为风险。
