风险评分模型库

一、Altman Z-Score 破产预警模型

（一）模型用途
Altman Z-Score 用于评估企业的财务困境（破产）概率，是国际公认的经典财务预警模型。得分越低，财务困境风险越高。

（二）三个变体及适用范围

1. 原始 Z-Score（适用于上市制造业企业）
公式：Z = 1.2×X1 + 1.4×X2 + 3.3×X3 + 0.6×X4 + 1.0×X5
X1 = 营运资金 / 总资产，其中营运资金 = 流动资产 - 流动负债
X2 = 留存收益 / 总资产（留存收益可用未分配利润+盈余公积近似）
X3 = 息税前利润(EBIT) / 总资产，EBIT = 利润总额 + 利息费用
X4 = 股权市值 / 总负债（无市值数据时改用 Z'-Score）
X5 = 营业收入 / 总资产
判定区间：Z > 2.99 财务安全区；1.81 ≤ Z ≤ 2.99 灰色预警区；Z < 1.81 财务困境区

2. Z'-Score（适用于非上市企业，或缺少市值数据时）
公式：Z' = 0.717×X1 + 0.847×X2 + 3.107×X3 + 0.420×X4' + 0.998×X5
X4' = 股东权益账面价值 / 总负债（其余变量同上）
判定区间：Z' > 2.90 安全区；1.23 ≤ Z' ≤ 2.90 灰色区；Z' < 1.23 困境区

3. Z''-Score（适用于非制造业企业及新兴市场企业，不含 X5 以消除行业周转差异）
公式：Z'' = 6.56×X1 + 3.26×X2 + 6.72×X3 + 1.05×X4'
判定区间：Z'' > 2.60 安全区；1.10 ≤ Z'' ≤ 2.60 灰色区；Z'' < 1.10 困境区

（三）模型选择规则
1. 行业为制造业且能获取股权市值：使用原始 Z-Score。
2. 行业为制造业但无市值数据：使用 Z'-Score。
3. 行业为非制造业（服务业、互联网、金融、房地产、商贸零售等）：使用 Z''-Score。
4. 金融业企业适用性较弱，因其资产负债结构特殊，结果仅作参考并须标注该局限。

（四）使用局限
1. 模型基于历史样本统计，对不同市场与年代存在系统性偏差。
2. 单期 Z 值不足以定性，应观察连续多期趋势；连续下降且跌入困境区的信号价值远高于单期数值。
3. Z-Score 低不等于必然破产，仅表示财务困境概率显著上升，须表述为"存在财务困境风险嫌疑"。

二、Beneish M-Score 盈余操纵预警模型

（一）模型用途
Beneish M-Score 用于识别企业是否存在盈余操纵（earnings manipulation）的可能性，通过八项财务指标的期间变化捕捉操纵特征。得分越高，操纵嫌疑越大。

（二）八变量完整模型
公式：
M = -4.84 + 0.920×DSRI + 0.528×GMI + 0.404×AQI + 0.892×SGI + 0.115×DEPI - 0.172×SGAI + 4.679×TATA - 0.327×LVGI

各变量定义（下标 t 为本期，t-1 为上期）：
1. DSRI（应收账款指数）=（应收账款_t / 营业收入_t）/（应收账款_t-1 / 营业收入_t-1）
   含义：应收占收入比例异常上升，可能虚增收入。
2. GMI（毛利率指数）= 毛利率_t-1 / 毛利率_t
   含义：毛利率恶化，公司有粉饰业绩的动机。
3. AQI（资产质量指数）=（1 -（流动资产_t + 固定资产_t）/ 总资产_t）/（1 -（流动资产_t-1 + 固定资产_t-1）/ 总资产_t-1）
   含义：非流动非固定资产占比上升，可能存在费用资本化。
4. SGI（营收增长指数）= 营业收入_t / 营业收入_t-1
   含义：高增长企业面临维持增长的压力，操纵动机更强。
5. DEPI（折旧率指数）= 折旧率_t-1 / 折旧率_t，其中折旧率 = 折旧额 /（折旧额 + 固定资产原值）
   含义：折旧率下降，可能通过延长折旧年限抬高利润。
6. SGAI（销售管理费用指数）=（销售费用+管理费用）_t / 营业收入_t 除以 上期同一比率
   含义：费用率上升被视为负面信号（系数为负）。
7. TATA（总应计利润占比）=（持续经营利润 - 经营活动现金流量净额）/ 总资产_t
   含义：利润与现金流背离越大，应计利润越高，操纵嫌疑越大。该项权重最高（4.679），是模型中最关键的变量。
8. LVGI（财务杠杆指数）= 资产负债率_t / 资产负债率_t-1
   含义：杠杆变化（系数为负）。

判定阈值：M > -1.78 表示存在盈余操纵嫌疑；M ≤ -1.78 表示未发现明显操纵特征。
M 值越高嫌疑越大，M > -1.00 属高度可疑。

（三）五变量简化模型（数据缺失时降级使用）
公式：M5 = -6.065 + 0.823×DSRI + 0.906×GMI + 0.593×AQI + 0.717×SGI + 0.107×DEPI
判定阈值：M5 > -2.22 表示存在盈余操纵嫌疑。
适用场景：无法获取折旧明细、费用明细或现金流数据时，使用五变量模型并标注置信度为"中"。

（四）计算规则与降级策略
1. 任一变量的分母为零或缺失时，该变量按 1.0（中性值）处理，并在结果中标注"该因子缺失，按中性值代入"。
2. 缺失变量数 0 个：置信度=高；缺失 1-2 个：置信度=中；缺失 3 个及以上：不输出 M-Score 结论，仅列出可得因子供人工判断。
3. TATA 缺失（无经营现金流数据）时必须降级为五变量模型，因该项权重最高，缺失会严重失真。

（五）使用局限
1. 模型对制造业与商贸业识别效果较好，对金融业、房地产业适用性较弱。
2. M-Score 超过阈值仅表示财务特征与历史操纵样本相似，不能作为造假的证据，须表述为"存在盈余操纵风险嫌疑，建议结合审计意见与关联交易情况进一步核查"。
3. 应与 Z-Score 交叉使用：Z 低（财务困境）+ M 高（操纵嫌疑）的组合，是最高风险的信号组合，指向"经营恶化且可能通过会计手段掩饰"。

三、本系统综合风险评分口径

（一）评分方向（关键，不得误读）
本系统的综合风险分为 0-100 分，**分数越高表示风险越大**（风险分，非健康分）。

（二）三维度权重（与工具实现一致）
财务指标风险：50%
披露合规风险：30%
数据校验风险：20%

（三）风险等级映射
得分 ≤ 25：低风险（各项指标基本正常）
25 < 得分 ≤ 50：中等风险（存在一定风险信号，建议关注）
50 < 得分 ≤ 75：高风险（存在较多风险信号，建议重点核查）
得分 > 75：极高风险（存在重大风险信号，建议全面深入核查）

（四）风险维度定性分类（用于单条风险的等级标注，与综合分独立）
重大（红）：指标严重偏离且多方交叉印证
重要（橙）：指标偏离行业基准超过 50% 但缺确凿证据链
一般（蓝）：报表格式或附注程序性瑕疵

（五）量化模型对评分的影响规则
1. Altman Z-Score 位于困境区：持续经营相关风险等级不低于"重要"。
2. Altman Z-Score 连续两期下降且跌破灰色区下限：额外触发"持续经营风险嫌疑"独立风险条目。
3. Beneish M-Score 超过阈值：财务错报相关风险等级不低于"重要"。
4. Z 低且 M 高同时成立：风险等级不低于"重大"，并在综合结论中明确标注"财务困境与盈余操纵双重信号并存"。
5. 审计意见为保留/否定/无法表示：披露与财务错报两维度风险均上调，综合风险等级不低于"重大"。
6. 审计意见为带强调事项段的无保留：不直接判定高风险，按强调事项内容归入对应维度。

（六）置信度映射
confidence ≥ 0.7：高度关注
0.5 ≤ confidence < 0.7：建议关注
confidence < 0.5：待进一步核实

四、模型结果的表述规范

引用 Z-Score 与 M-Score 结论时，必须同时说明：（1）所用模型变体及原因；（2）各因子取值；（3）判定区间；（4）模型局限与置信度。禁止仅给出一个分值即下定性结论。规范表述示例："采用 Z''-Score（非制造业变体，因公司属互联网行业且无完整市值数据），得分 1.05，落入财务困境区（阈值 1.10），提示存在财务困境风险嫌疑；该模型对新兴行业存在系统性偏差，建议结合经营现金流趋势进一步核查。"
