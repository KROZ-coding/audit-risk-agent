三大财务报表勾稽关系

一、各表内部勾稽关系

资产负债表：
资产 = 负债 + 所有者权益
固定资产净值 = 固定资产原值 - 累计折旧
未分配利润期末数 - 年初数 = 利润表中净利润(累计数)

利润表：
利润 = 收入 - 费用
净利润 = 收入 - 成本 - 费用

现金流量表：
现金净流量 = 现金流入 - 现金流出
现金及现金等价物净增加额 = 经营活动现金流量净额 + 投资活动现金流量净额 + 筹资活动现金流量净额

二、表间勾稽关系

资产负债表与利润表：
资产 + 费用 = 负债 + 所有者权益 + 收入
利润表"净利润" = 资产负债表"未分配利润"期末数 - 年初数 + 本年度分配的利润 - 年初未分配利润
投资收益与短期投资、长期投资存在勾稽关系
管理费用-折旧费与固定资产、累计折旧存在勾稽关系

资产负债表与现金流量表：
现金及现金等价物净额 = 资产负债表"货币资金"期末金额 - 期初金额
销售商品收到的现金 ≈ (主营业务收入+其他业务收入)×(1+增值税率) + 预收账款增加额 - 应收账款增加额 - 应收票据增加额
购买商品支付的现金 ≈ (主营业务成本+其他业务成本+存货增加额)×(1+增值税率) + 预付账款增加额 - 应付账款增加额 - 应付票据增加额

利润表与现金流量表：
净利润 ± 经营活动非现金的资产和负债的变化 = 经营活动现金流量净额

审计校验要点：
1. 货币资金期末数与现金流量表"现金及等价物期末余额"是否一致
2. 净利润与经营现金流的偏离度是否合理
3. 应收账款增长与收入增长是否匹配
4. 存货变动与营业成本是否匹配
