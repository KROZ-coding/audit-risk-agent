关联交易审查库

一、关联方的界定标准

（一）依据《企业会计准则第36号——关联方披露》
一方控制、共同控制另一方或对另一方施加重大影响，以及两方或多方同受一方控制、共同控制或重大影响的，构成关联方。

（二）常见关联方类型
1. 该企业的母公司及母公司控制的其他企业。
2. 该企业的子公司、合营企业、联营企业。
3. 该企业的主要投资者个人及其关系密切的家庭成员。
4. 该企业或其母公司的关键管理人员及其关系密切的家庭成员。
5. 主要投资者个人、关键管理人员控制或共同控制的其他企业。
6. 实际控制人及其一致行动人。

（三）不构成关联方的情形
仅仅同受国家控股而不存在其他关联关系的企业，不构成关联方；与企业发生大量交易而形成经济依存关系的单一供应商、客户、代理商等，也不因此构成关联方（但需作为客户/供应商集中度风险单独评估）。

二、关联交易的披露要求

（一）依据《上市公司信息披露管理办法》与交易所上市规则
1. 上市公司应披露关联方关系及其交易的性质、类型、金额、定价政策。
2. 达到规定标准的关联交易须经独立董事事前认可、董事会或股东大会审议，关联董事/股东须回避表决。
3. 持续性关联交易应披露年度预计总额，实际发生额超出预计总额须重新履行审议程序并披露。
4. 关联方资金往来（尤其是非经营性占用）须专项披露。

（二）披露质量的判定要点
1. 是否披露了定价依据（市场价、成本加成、协议价），仅笼统写"参照市场价格"属披露不充分。
2. 是否披露了关联交易占同类交易的比例。
3. 实际发生额是否超出预计额度，超出后是否补充履行程序。
4. 是否存在应披露而未披露的关联方（可通过股权结构、董监高兼职、异常客户供应商名称比对发现线索）。

三、常见利润操纵手法（通过关联交易实现）

1. 关联方增收入
向关联方销售商品或提供服务以虚增收入，特征：关联销售占比高、关联应收账款账龄长且回款慢、销售毛利率显著高于第三方交易。

2. 关联方承担费用
由关联方代为承担销售、管理、研发费用，使上市公司费用率异常偏低。特征：费用率显著低于同行业且无合理解释。

3. 转移定价调节利润
关联采购价格低于市场价以降低成本，或关联销售价格高于市场价以提高收入。特征：与关联方交易的毛利率与第三方交易存在显著差异。

4. 资产腾挪与出售
在业绩不达预期时向关联方出售资产确认投资收益。特征：非经常性损益占利润总额比例高、出售时点集中在年末、交易对手为关联方。

5. 关联方资金占用
以预付款、其他应收款、往来款等名义被大股东或关联方占用资金。特征：其他应收款/总资产比例偏高（超过 5% 需重点关注）、无明确账龄与用途说明。

6. 关联方担保与代偿
为关联方提供担保形成表外负债，或关联方债务由上市公司代偿。特征：担保总额占净资产比例高、被担保方财务状况恶化。

7. 借助合营/联营企业出表
将亏损业务或负债转入合营联营企业以美化合并报表。特征：长期股权投资规模快速增长、投资收益波动剧烈、合营方与公司存在关联关系。

四、量化审查指标与阈值

1. 关联采购占营业成本比例 > 30%：高度依赖关联方，须核查定价公允性。
2. 关联销售占营业收入比例 > 30%：收入独立性存疑。
3. 其他应收款 / 总资产 > 5%：关注是否存在资金占用。
4. 大股东股权质押比例 > 70%：控股股东资金链紧张，占用上市公司资金的动机上升。
5. 对外担保总额 / 净资产 > 50%：担保风险显著。
6. 关联交易实际发生额 / 预计额度 > 100%：程序合规性存疑。
7. 关联方应收账款账龄超过一年的占比 > 30%：回款异常。

五、监管审查关注点

1. 交易的必要性与商业合理性：是否具有真实的业务需求，还是纯粹为调节报表。
2. 定价的公允性：是否有可比的第三方交易价格作为参照。
3. 决策程序的合规性：独立董事意见、关联方回避表决、审议层级是否正确。
4. 资金流向的真实性：是否存在资金体外循环或最终回流至关联方。
5. 交易时点的异常性：是否集中在会计期末，用于突击调节业绩。
6. 交易的可持续性：一次性关联交易贡献的利润不具有可持续性，应在评估盈利质量时剔除。

六、交叉验证方法

关联交易风险不应孤立判断，须与以下信号交叉印证：
1. 关联销售占比高 + 应收账款周转率下降 → 收入真实性风险嫌疑上升。
2. 关联采购占比高 + 毛利率异常高于同业 → 成本转移嫌疑。
3. 其他应收款高 + 大股东高比例质押 → 资金占用嫌疑显著。
4. 年末大额关联资产出售 + 扣非净利润为负 → 利润操纵嫌疑。
5. 审计报告将关联交易列为关键审计事项 → 该领域已被注册会计师识别为高风险。

七、表述规范

描述关联交易风险时，应客观列出交易金额、占比、定价方式与程序履行情况，采用"存在××风险嫌疑，建议进一步核查定价公允性与资金流向"的审慎表述，不得直接认定利润操纵或资金占用事实。
