行业经营风险特征库

本库列出不同行业典型的经营风险信号，用于在财务指标之外识别行业特有的经营层面风险。使用时须先确定公司所属行业，再对照本行业的特征信号排查。

一、房地产业

核心风险信号：
1. 销售回款率下降：销售商品收到的现金/合同销售额持续下降，反映去化困难或按揭放款受限。
2. 存货（开发产品）周转放缓：存货规模持续增长而结转收入未同步，指向滞销风险。
3. 短期偿债压力：一年内到期的有息负债/货币资金 > 1，流动性风险显著。
4. 土地储备结构：三四线城市土储占比过高，面临去化压力。
5. 表外负债：合作项目、明股实债、供应链融资可能形成未在报表体现的负债。
6. 预收账款（合同负债）下降：反映未来收入储备减少。
关注重点：净负债率、现金短债比、权益销售额与全口径销售额的差异。

二、医药与生物制品业

核心风险信号：
1. 研发费用资本化：资本化率显著高于同业，可能虚增利润与无形资产。
2. 销售费用率异常高：可能涉及商业贿赂或带金销售的合规风险。
3. 集采政策冲击：核心产品被纳入集中采购导致价格大幅下降，收入与毛利率断崖式下滑。
4. 单一产品依赖：单一品种收入占比过高，一旦专利到期或政策变动，业绩剧烈波动。
5. 临床试验失败风险：在研管线终止导致已资本化开发支出需全额减值。
6. 应收账款账期：以医院为主要客户时账期偏长属常态，但持续拉长需关注。

三、制造业

核心风险信号：
1. 产能利用率下降：固定资产规模扩张但产量或收入未同步增长，指向产能过剩。
2. 原材料价格传导能力弱：原材料涨价而毛利率同步下降，说明缺乏定价权。
3. 存货积压：存货增速远超营业收入增速，且存货跌价准备计提不足。
4. 应收账款集中：前五大客户占比过高，客户信用风险集中。
5. 在建工程长期挂账：在建工程长期不转固，可能延迟折旧以美化利润。
6. 环保与安全合规：环保处罚、停产整改会直接影响产能与收入。

四、互联网与信息技术业

核心风险信号：
1. 用户增长停滞：活跃用户数或付费转化率下降，收入增长不可持续。
2. 获客成本上升：销售费用增速远超收入增速，单位经济模型恶化。
3. 商誉高企：频繁并购形成大额商誉，标的业绩不达预期即触发减值。
4. 合同负债与递延收入结构：预收模式下需关注收入确认节奏是否合规。
5. 数据合规风险：数据安全、个人信息保护相关的监管处罚风险上升。
6. 研发人员流失：核心技术人员变动影响持续创新能力。

五、商贸零售业

核心风险信号：
1. 同店销售额下滑：反映主业竞争力下降，区别于因新开门店带来的总收入增长。
2. 存货周转天数上升：滞销与库存减值风险。
3. 供应商账期被压缩：应付账款周转天数下降，反映议价能力或信用状况恶化。
4. 门店扩张与租金压力：使用权资产与租赁负债规模扩大，固定成本刚性上升。
5. 线上渠道替代：传统门店渠道被电商挤压，收入结构转型不畅。

六、建筑与工程业

核心风险信号：
1. 合同资产（已完工未结算）规模持续膨胀：结算与回款风险。
2. 应收账款账龄拉长：业主方（尤其是地方政府平台）付款能力恶化。
3. 新签合同额下降：未来收入储备减少。
4. 垫资施工：经营现金流长期为负，依赖外部融资维持。
5. 履约保证金与担保：或有负债规模需关注。

七、能源与公用事业

核心风险信号：
1. 电价/气价管制：价格受政府管制，成本上涨无法完全传导。
2. 资本开支强度：长期大额资本支出导致自由现金流长期为负。
3. 政策补贴依赖：补贴占利润比例高，政策调整即冲击业绩。
4. 环保转型压力：传统能源企业面临碳减排改造投入。

八、农林牧渔业

核心风险信号：
1. 生物资产计量主观：消耗性与生产性生物资产的盘点与计价难以验证，是历史造假高发领域。
2. 自然灾害与疫病：不可控事件导致资产大幅减值。
3. 现金交易比例高：向农户收购的现金交易难以追溯，收入与成本真实性核查困难。
4. 价格周期波动：农产品价格周期性剧烈波动。

九、文化传媒业

核心风险信号：
1. 商誉减值：影视、游戏公司并购频繁，商誉占净资产比例高。
2. 内容资产（版权、剧本）估值主观：摊销政策与减值判断空间大。
3. 内容审核与政策监管：作品无法上线导致存货报废。
4. 应收账款回收：向平台方或广告主的账期长且集中。
5. 明星或核心创作者依赖：关键人员风险。

十、金融业（银行、证券、保险）

核心风险信号：
1. 不良贷款率与关注类贷款迁徙：资产质量恶化的先行指标。
2. 拨备覆盖率下降：风险抵御能力削弱，或存在通过少计提拨备调节利润的嫌疑。
3. 净息差收窄：盈利能力承压。
4. 资本充足率接近监管红线：扩张受限并可能需要再融资。
5. 表外理财与资管业务：风险是否实质隔离。
6. 通用财务模型（Z-Score、M-Score）适用性弱：须以行业专用监管指标为主。

十一、汽车与零部件业

核心风险信号：
1. 主机厂订单集中：单一主机厂占比过高，主机厂降价压力直接传导。
2. 新能源转型：传统燃油车零部件业务面临替代风险，需关注产品结构转型进度。
3. 产能扩张与利用率：新建产能落地但订单未同步。
4. 质量索赔与召回：形成或有负债。

十二、跨行业通用经营风险信号

1. 核心管理层或财务负责人频繁变动。
2. 会计师事务所连续变更（尤其是在收到非标意见后）。
3. 控股股东高比例股权质押（超过 70%）。
4. 主要子公司或核心资产被查封、冻结。
5. 主营业务与实际投资方向背离（募集资金变更用途）。
6. 关键客户或供应商与公司存在未披露关联关系。

十三、使用规范

行业经营风险信号属定性判断依据，须与财务指标交叉印证后才可形成风险条目。表述时应说明信号来源（年报管理层讨论、附注或公开信息）并采用审慎措辞，例如"公司所处行业面临××风险，结合公司××指标表现，存在××风险嫌疑，建议进一步核查"。
