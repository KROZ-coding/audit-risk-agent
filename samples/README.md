# 示例产物 (samples/)

本目录存放**纳入版本库的示例产物**，用于文档展示、演示与答辩，
与运行期自动生成的产物相互隔离。

## 目录说明

- `charts/` — 系统生成的图表示例（财务雷达图、风险热力图、趋势图各一张）。
  图片由 `scripts/generate_sample_charts.py` 用**虚构公司「华信智造科技」的
  合成数据**生成（数据自洽、不对应任何真实企业），仅作示例，
  **不会**被应用覆盖或读取。

## 与运行期产物的区别

| 类型 | 位置 | 是否纳入版本库 | 说明 |
| --- | --- | --- | --- |
| 示例产物 | `samples/` | ✅ 是 | 手工挑选、稳定不变，供文档/演示引用 |
| 运行期产物 | `local_storage/`、`src/local_storage/` | ❌ 否（.gitignore 已忽略） | 应用运行时自动生成，目录会自动创建 |
| 运行日志 | `*.log` | ❌ 否 | 运行时生成 |
| 向量库 / 检查点 | `.chroma_db/`、`checkpoints.sqlite` | ❌ 否 | 运行时生成 |

> 运行期产物由应用在启动或运行时通过 `os.makedirs(..., exist_ok=True)` 自动创建
> （见 `src/main.py`、`src/local_storage.py`），无需手动建立目录，也无需提交到仓库。
