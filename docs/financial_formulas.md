# 财务指标计算公式手册

本文档列出系统 `src/tools/financial_calculator.py` 中用于年报分析的核心财务指标、审计关注指标及其预警阈值。指标输入缺失时不补零；相关字段全部未披露时不生成空的未计算条目。

---

## 一、盈利能力指标

### 1. 营业收入同比增长率

$$\text{营业收入同比增长率} = \frac{\text{本期营业收入} - \text{上期营业收入}}{|\text{上期营业收入}|} \times 100\%$$

- **预警阈值**：绝对值 > 30%
- **含义**：检测收入异常增长或下滑

### 2. 净利润同比变动率

$$\text{净利润同比变动率} = \frac{\text{本期净利润} - \text{上期净利润}}{|\text{上期净利润}|} \times 100\%$$

- **预警阈值**：绝对值 > 50%
- **特殊处理**：上期净利润为负时百分比无良好定义，改用定性描述（扭亏为盈 / 亏损收窄 / 亏损扩大）

### 3. 毛利率

$$\text{毛利率} = \frac{\text{营业收入} - \text{营业成本}}{\text{营业收入}} \times 100\%$$

- **预警阈值**：对比行业基准（如制造业 25%、互联网 60%、医药 65%）
- **含义**：衡量核心盈利能力

系统同时计算销售净利率、营业利润率、净资产收益率（加权与扣非）、总资产报酬率（ROA）、每股收益（EPS）和每股净资产。各项指标均保留计算公式、输入值及单位、期间/口径、代入过程、结果、阈值来源和原文定位；缺少必要字段时标记为未获取，不以中性值替代。

## 二、现金流质量指标

### 4. 现金流质量指标

$$\text{OCF/NP 比} = \frac{\text{经营活动现金流量净额}}{\text{净利润}}$$

- **预警阈值**：< 0.5（且净利润 > 0 时）
- **含义**：比值低说明利润缺乏现金流支撑，需要进一步复核利润质量
- **附加预警**：营收增长但经营现金流为负 → 盈利质量需结合原始凭证和回款资料复核

现金流质量还包括经营现金流/营业收入、经营现金流/总负债、经营现金流/总资产和自由现金流。经营现金流/总资产为：

$$\text{经营现金流/总资产} = \frac{\text{经营活动现金流量净额}}{\text{期末总资产}} \times 100\%$$

现金流质量单独成组，不与盈利能力混列。

## 三、营运能力指标

### 5. 应收账款占营收比

$$\text{应收账款占营收比} = \frac{\text{应收账款}}{\text{营业收入}} \times 100\%$$

- **预警阈值**：> 30%
- **含义**：过高可能存在提前确认收入或虚构收入

### 6. 应收增速 vs 营收增速

$$\text{应收增速} = \frac{\text{本期应收} - \text{上期应收}}{|\text{上期应收}|} \times 100\%$$

- **预警条件**：应收增速 > 营收增速 + 20 个百分点
- **含义**：应收增速显著高于营收增速，可能存在放宽信用政策或提前确认收入

### 7. 存货周转率

$$\text{存货周转率} = \frac{\text{营业成本}}{\frac{\text{期初存货} + \text{期末存货}}{2}}$$

- **预警条件**：存货同比增长 > 50%
- **含义**：周转率下降或存货激增需关注跌价风险

## 四、偿债能力指标

### 8. 资产负债率

$$\text{资产负债率} = \frac{\text{总负债}}{\text{总资产}} \times 100\%$$

- **预警阈值**：> 70%
- **含义**：财务杠杆过高，偿债压力大

### 9. 流动比率

$$\text{流动比率} = \frac{\text{流动资产}}{\text{流动负债}}$$

- **预警阈值**：< 1
- **含义**：流动资产不足以覆盖流动负债，短期偿债能力不足

### 10. 速动比率

$$\text{速动比率} = \frac{\text{流动资产} - \text{存货}}{\text{流动负债}}$$

- **预警阈值**：< 0.5
- **含义**：扣除存货后的更严格流动性指标

## 五、特殊风险信号

### 11. 商誉占净资产比

$$\text{商誉占净资产比} = \frac{\text{商誉}}{\text{净资产}} \times 100\%$$

- **预警阈值**：> 30%
- **含义**：商誉减值可能对净资产造成重大冲击

### 12. 在建工程变动率

$$\text{在建工程变动率} = \frac{\text{本期在建工程} - \text{上期在建工程}}{|\text{上期在建工程}|} \times 100\%$$

- **预警条件**：变动幅度过大时需关注资本化支出合理性

### 13. 其他应收款占总资产比

$$\text{其他应收款占比} = \frac{\text{其他应收款}}{\text{总资产}} \times 100\%$$

- **预警阈值**：> 5%
- **含义**：可能存在大股东或关联方资金占用

### 14. 存贷双高检测

**判定条件**（同时满足即预警）：

$$\text{货币资金} > \text{短期借款} \quad \text{且} \quad \text{利息支出} > 2 \times \text{利息收入}$$

- **含义**：账面资金充裕却大量借贷并承担高额利息支出，典型财务造假信号（如康美药业案）

### 15. 连续亏损检测

**判定条件**：

$$\text{本期净利润} < 0 \quad \text{且} \quad \text{上期净利润} < 0$$

- **含义**：连续两年净利润为负，触发持续经营疑虑

### 16. 经营现金流连续为负

**判定条件**：

$$\text{本期经营现金流} < 0 \quad \text{且} \quad \text{上期经营现金流} < 0$$

- **含义**：经营活动持续"失血"，进一步验证持续经营能力

## 七、辅助函数

### 安全除法 `_safe_div(a, b)`

```
若 b = 0 或 a/b 任一为 None → 返回 None
否则 → round(a / b, 4)
```

### 同比变动 `_pct_change(current, previous)`

```
若 previous = 0 或 None → 返回 None
若 previous < 0 → 返回 None（上期为负时百分比无意义）
否则 → round((current - previous) / |previous| × 100, 2)
```
