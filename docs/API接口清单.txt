上市公司年报风险智能识别系统 v5.3 GA — API 接口清单
==============================================================================

说明：本清单列出系统全部 HTTP 接口、SSE 事件协议、工具链与 LLM 可调用工具。
接口定义源文件：src/main.py；工具白名单源文件：config/agent_llm_config.json。
鉴权说明：X-API-Key 是"服务访问密钥"（APP_API_KEY 为空则完全放行）；
          X-Auth-Token 是"用户会话令牌"（登录后签发，7 天有效）。两者互相独立。

【二】SSE 事件协议
----------------------------------------------------------------------------
后端固定输出格式（src/main.py::_sse）：

    event: message
    data: {"type": "...", ...}
    <空行>

事件名恒为 message，真实类型由 JSON 的 type 字段区分，共四类：

type              含义                  关键字段
----------------------------------------------------------------------------
progress          分析进度              step(阶段名), percent(百分比)
final_report      最终结构化报告        percent:100 + 报告全部字段
artifact_status   产物生成状态          产物清单/状态（PDF/Excel/图表）
error             通用错误（已脱敏）    content

设计说明：
1. 固定事件名 + data.type，前端只需一个 onmessage 分支，减少浏览器差异；
2. 进度单调不减：current_pct = max(current_pct, pct)，乱序/重复不会倒退；
3. AI 正文流每来一段 +1 且封顶 96，最终报告固定 100。

【四】16 个 LLM 可调用工具
----------------------------------------------------------------------------
源文件：config/agent_llm_config.json 的 tools 数组

 1. parse_pdf_report                 解析年报文件（PDF/Excel/Word/CSV/HTML/PPT/TXT）
 2. validate_financial_data          三大勾稽校验
 3. calculate_financial_indicators   核心财务指标计算
 4. calculate_risk_models            Altman Z-Score + Beneish M-Score
 5. check_disclosure_compliance      披露合规检查
 6. identify_audit_opinion           审计意见类型识别
 7. search_regulations               法规条文语义检索（RAG）
 8. search_regulatory_inquiries      监管问询/处罚检索
 9. industry_outlook                 行业风向研判
10. compare_multi_year               多年指标时序对比
11. calculate_comprehensive_score    三维加权综合评分
12. generate_risk_heatmap            风险热力图
13. generate_radar_chart             财务五维雷达图
14. generate_trend_chart             多年趋势折线图
15. investment_advisor               投资参考卡（轻量路径）
16. batch_analyze_companies          多公司批量分析

调用约定：
- 入参为 JSON 字符串（模型生成文本而非结构化对象），工具内部先 json.loads；
- 出参为字符串，通常为 JSON（含 status/data/warnings），便于模型再推理；
- 失败不抛异常，返回 {"status":"error", ...}，避免整链中断；
- 数值结果带 source/evidence/calculation_version 等可追溯字段。

【五】模块路由与工具裁剪
----------------------------------------------------------------------------
标记（src/main.py::MODULE_MARKERS，扫描全部消息）：
    【模块:财务健康度诊断】    -> financial
    【模块:合规与经营风险扫描】 -> compliance
    【模块:综合研判】          -> synthesis
    【模块:行业风向研判】      -> outlook

轻量标记（src/main.py::LIGHT_MARKERS，只扫最后一条消息）：
    【工具:投资参考】          -> advisor
    【工具:行业风向】          -> industry

模块 -> 工具集（src/agents/agent.py::MODULE_TOOLS / LIGHT_MODULE_TOOLS）：
    financial : parse / validate / calculate / compare_multi_year /
                risk_models / heatmap? (radar+tred) -> 7 项
    compliance: parse / disclosure / audit_opinion / search_regulations -> 4 项
    synthesis : comprehensive_score / risk_models / search_regulations /
                risk_heatmap -> 4 项
    outlook   : industry_outlook / search_regulations /
                search_regulatory_inquiries -> 3 项
    advisor   : parse / validate / calculate / comprehensive_score /
                investment_advisor / regulatory_inquiries / industry_outlook -> 7 项
    industry  : industry_outlook / search_regulations -> 2 项

综合研判三段串跑（src/agents/pipeline.py::SYNTHESIS_STAGES）：
    第一阶段 财务健康度诊断（5%~35%）  ┐
    第二阶段 合规与经营风险扫描（35%~65%）├ 前两阶段 asyncio.gather 并行
    第三阶段 综合研判与交叉验证（65%~95%）┘ 第三阶段依赖前两段结论

综合研判预处理接入（实测修复）：
    进入三段串跑前，先执行一次 P1 预处理（parse_pdf_report + 摘录选页 +
    字段回填 + 报告身份确定性兜底），产出 pre_msgs / pre_entries /
    pre_tool_results；随后 yield("tool_results", pre_entries) 推送预跑台账
    并推进进度至 8/42。财务阶段将预跑轨迹追加到 build_stage_payload 之后
    （保证 messages[-1] 仍是人类问题），汇合处以 setdefault 保证预跑结果优先。
    该修复消除了综合研判模式下成片"未检测出/未获取"。

【七】LLM 调用配置
----------------------------------------------------------------------------
协议      : OpenAI 兼容（LangChain ChatOpenAI）
地址      : OPENAI_BASE_URL（默认 https://api.deepseek.com）
主模型    : config/agent_llm_config.json -> config.model
快速模式  : FAST_MODEL（默认 deepseek-v4-flash）
辩论复核  : REVIEW_MODEL（默认 deepseek-v4-flash）
参数      : temperature / top_p / max_tokens（默认 16000）
            timeout（默认 600 秒）/ max_retries = LLM_MAX_RETRIES（默认 2）
            streaming = True
上下文    : _windowed_messages 配对安全滑窗（MAX_MESSAGES = 40）
            + _merge_tool_ledger 工具台账（与 messages 解耦）

【八】错误码约定
----------------------------------------------------------------------------
HTTP 400  入参非法（缺字段、格式不支持、mode 非法）
HTTP 401  缺少或错误的 X-API-Key / X-Auth-Token
HTTP 404  资源不存在；历史记录他人访问与不存在统一 404（防探测）
HTTP 413  上传文件超过 100MB 上限
HTTP 200  业务失败也可能返回 200 + {"status":"error", ...}（如 /api/reload_kb）

对外错误一律脱敏：只回通用提示，路径/密钥/堆栈只写服务端日志。
