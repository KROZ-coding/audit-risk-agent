上市公司年报风险智能识别系统 v5.3 GA — 环境变量与关键常量清单
==============================================================================

说明：本清单列出系统全部可配置环境变量及其默认值，以及影响行为与结论的关键
      算法常量。修改常量需同步更新 tests/ 下的对应断言，否则 CI 会失败。

----------------------------------------------------------------------------
【一】模型与 LLM 配置
----------------------------------------------------------------------------
变量名                  默认值                        说明
----------------------------------------------------------------------------
OPENAI_API_KEY          （必填，无默认）              模型服务密钥。
                                                       示例占位值 sk-your-* 会被
                                                       /api/status 判定为"未配置"。
OPENAI_BASE_URL         https://api.deepseek.com     OpenAI 兼容服务地址。
                                                       备选: 通义千问
                                                       https://dashscope.aliyuncs.com/
                                                       compatible-mode/v1
                                                       智谱 https://open.bigmodel.cn/
                                                       api/paas/v4
FAST_MODEL              deepseek-v4-flash             快速模式主分析模型（前端 ⚡
                                                       开关或"快速模式"关键词生效）。
REVIEW_MODEL            deepseek-v4-flash             三方辩论复核专用模型。
LLM_MAX_RETRIES         2                             模型调用失败后的额外重试次数。
                                                       重试计入审查预算。
LLM_RETRY_BASE_DELAY    1.5                           指数退避基准秒数（delay =
                                                       base * 2^attempt）。

注：主分析模型名不通过环境变量设置，读
    config/agent_llm_config.json -> config.model。
    temperature / top_p / max_completion_tokens / timeout 也来自该文件。

【六】运行时资源定期回收（maintenance）
----------------------------------------------------------------------------
变量名                                默认值   说明
----------------------------------------------------------------------------
MAINTENANCE_ENABLED                   true     后台定期回收总开关；
                                                false 完全停用。
MAINTENANCE_INTERVAL_HOURS            24       回收周期（小时）。启动后先等待
                                                min(60, max(5, 周期分钟数)) 秒
                                                再执行首次回收，避免与首屏争 IO。
MAINTENANCE_DRY_RUN                   false    只预览不删除。上线初期建议设
                                                true 观察一次。
MAINTENANCE_CHECKPOINT_KEEP_THREADS   50       检查点库保留最近 N 个线程。
MAINTENANCE_CHECKPOINT_MAX_MB         512      检查点库超过该体积才回收
                                                （0 表示不按体积限制）。
MAINTENANCE_CHECKPOINT_VACUUM         true     回收后是否 VACUUM 收缩文件。
MAINTENANCE_ARTIFACT_RETENTION_DAYS   30       产物批次保留天数。
MAINTENANCE_ARTIFACT_MIN_BATCHES      10       产物批次最少保留个数（下限保护）。
MAINTENANCE_LOG_RETENTION_DAYS        14       轮转日志保留天数；
                                                当前 app.log 永不删除。
MAINTENANCE_TEMP_RETENTION_DAYS       7        .tmp_* 临时文件保留天数；
                                                .tmp_pytest 在保护名单。

命令行用法（scripts/maintenance_cli.py）：
    python scripts/maintenance_cli.py --dry-run         # 预览（默认即 dry-run）
    python scripts/maintenance_cli.py --apply           # 真正执行删除
    python scripts/maintenance_cli.py --apply --sections checkpoints,artifacts,logs,temp
    python scripts/maintenance_cli.py --json            # 机器可读输出
    python scripts/maintenance_cli.py --project-dir <路径>
退出码：正常 0；有 errors 1；未知 section 2。
只读观测接口：GET /api/maintenance/status（返回最近一次报告副本，不触发回收）。

3) 财务指标（src/tools/financial_calculator.py）
   CALCULATION_VERSION          = "2026-09-v4"    指标计算口径版本号。
   核心指标数                   = 16 项
   扩展指标数                   = 3 项（在建工程变动、其他应收/其他应付占总资产）
   条件指标数                   = 2 项（归母净利润同比、扣非归母同比，字段存在
                                        时才注册）
   单次最多指标数               = 21 条
   中期识别                     H1 用 date(year,7,1)-date(year,1,1) 算 181/182 天；
                                其他中期无明确天数返回 None；年度默认 365 天。

4) 数据勾稽（src/tools/data_validator.py）
   资产平衡阈值                 = 2%   ratio = diff / max(|assets|, |total|, 1)
   现金流勾稽阈值               = 15%  状态恒为 limited_check
   未分配利润阈值               = 5%   必须使用归母口径
   候选风险编号                  V001 / V002 / ...
   候选风险固定字段              dimension="数据可靠性风险"
                                level="待定级"  confidence=None
                                status="candidate"  verification_status="待复核"

5) 综合评分（src/tools/risk_scorer.py）
   WEIGHTS                      = {financial: 0.50, disclosure: 0.30,
                                   validation: 0.20}
   维度权重归一化                weight_sum = ΣWEIGHTS[k]（仅已获取维度）；
                                base = Σ(v_k * W_k) / weight_sum
   RISK_LEVELS                  = [(25,"低风险","low"), (50,"中等风险","medium"),
                                   (75,"高风险","high"), (100,"极高风险","critical")]
                                取首个 score <= threshold
   财务维度每条 alert             +8；含重大/严重/持续经营/资不抵债/存贷双高/
                                连续 再 +5；上限 100
   校验维度                      failed_checks × 30；上限 100
   披露维度                      直接取披露检查的 risk_score
   抬分：Z+M 双信号               +20
   抬分：Z 或 M 单信号            +10
   抬分：审计意见保留/否定/无法表示 +25
   抬分：仅 going_concern.flagged  +15
   Z 基本面豁免                   debt_to_asset_ratio_pct < 55 且
                                (operating_cashflow_current > 0 或
                                 current_ratio >= 1) -> z_waived
   最终分                        score = round(min(100, max(0, base+escalation)), 1)
   异常兜底                      status="failed"  score=None
                                level_key="unavailable"
   calculation_version        = "2026-09-v3"

6) 量化模型（src/tools/risk_models.py）
   CALCULATION_VERSION          = "2026-09-v4"
   _Z_ZONES
       original  (safe=2.99, distress=1.81)
       private   (safe=2.90, distress=1.23)
       emerging  (safe=2.60, distress=1.10)
   _M8_THRESHOLD                = -1.78
   _M5_THRESHOLD                = -2.22
   高危判定                      high_suspicion = m > -1.00
   Z 公式：
       original: Z   = 1.2X1 + 1.4X2 + 3.3X3 + 0.6X4 + 1.0X5
       private:  Z'  = 0.717X1 + 0.847X2 + 3.107X3 + 0.420X4 + 0.998X5
       emerging: Z'' = 6.56X1 + 3.26X2 + 6.72X3 + 1.05X4（不用 X5）
   M8 公式：
       M = -4.84 + 0.920*DSRI + 0.528*GMI + 0.404*AQI + 0.892*SGI
           + 0.115*DEPI - 0.172*SGAI + 4.679*TATA - 0.327*LVGI
   M5 降级公式（TATA 不可用）：
       M5 = -6.065 + 0.823*DSRI + 0.906*GMI + 0.593*AQI + 0.717*SGI
            + 0.107*DEPI
   风险条目编号                  RM-Z-001（Z）/ RM-M-001（M）
   结论映射                      双信号=重大；单一=重要；
                                均未触发=一般；均未计算=None
   中期处理                      直接 not_applicable，不做机械年化

7) 披露合规（src/tools/disclosure_checker.py）
   必备章节 7 项                 公司基本情况 / 主要会计数据和财务指标 /

   负向模式 5 条                 NO_MATTER_PATTERNS（识别"无重大关联交易"等）
   审计意见优先级                无法表示 > 否定 > (?<!无)保留意见 >

   审计意见加分                  非标 risk_score += 15

   摘录模式                      is_excerpt=True 时两项置 None，保留 scan_score
   固定审慎字段                  compliance_conclusion="待复核提示，尚未作出实质合规认定"
