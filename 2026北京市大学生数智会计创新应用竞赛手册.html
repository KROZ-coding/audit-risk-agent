第一章 竞赛背景与意义

1.1 时代背景

近年来，以大语言模型（Large Language Model, LLM）为代表的人工智能技术发展迅猛，正在深刻重塑会计、审计、金融等专业领域的工作范式。智能体（Agent）作为 LLM 应用的高阶形态，能够自主感知、推理、决策与执行，已在风险识别、合同审阅、财务核对、投资研究等场景展现出显著价值。国务院发布的《新一代人工智能发展规划》明确提出，要推动人工智能与实体经济深度融合，培养具备AI 素养的复合型专业人才。

1.2 学科使命

中央财经大学会计学院作为国家会计、审计、财务管理人才培养的重要基地，肩负着引领会计学科数字化转型的历史使命。面对四大会计师事务所积极推进 AI 审计平台、大型企业部署财务智能体的产业趋势，学院亟需通过赛事载体，激励学生将所学的财会专业知识与前沿的智能体技术深度融合，培养「懂业务、会建模、能落地」的新一代财会复合型人才。

1.3 办赛目标

🤝 搭建产学研协作平台

连接高校学生、四大事务所、金融机构、AI 厂商，构建可持续生态。

💡 挖掘高水平创新成果

以真实业务场景为命题，催生具有产业落地价值的智能体作品。

🎓 培养复合型 AI 人才

让学生在赛程中完成从理论学习到工程实现的全流程历练。

🚀 引领学科建设方向

以赛事推动会计学院专业课程改革，反哺培养方案。

第二章 竞赛定位与主题

2.1 竞赛全名

中文全称：2026年北京市大学生数智会计创新应用竞赛

2.2 竞赛主题

「Multi-Agent」—— 让智能体走进财会专业领域

2.3 三大原则

原则说明
专业为本
Professional		所有作品必须立足真实的会计、审计、财务或金融业务场景，体现对专业知识的深刻理解，避免脱离业务的纯技术堆砌。
创新为魂
Innovation		鼓励多智能体协作、RAG 知识库、思维链、辩论机制、Agent-as-a-Judge 等前沿范式的创造性应用。
落地为王
Practical		作品必须有完整的可演示原型，能够在评审现场处理真实样例数据，输出可解释、可验证的结果。

2.4 价值定位

  • 专业深度：评审委员会由会计审计专家、行业专家、大数据技术专家三方组成，确保作品的专业含量，同时确保AI-agent能完全落地真实业务场景。
  • 产业链接：四大会计师事务所、头部金融机构提供赛题素材与实习内推机会，以及赛事奖金。

第三章 参赛对象与组队规则

3.1 参赛对象

北京市高校在校本科生

3.2 组队规则

每队人数4 人（校内组队）
专业建议至少 1 人具备会计/审计/财务/金融专业背景
指导教师每队可邀请 1名指导教师（专业导师）
参赛限制同一选手仅可参加 1 支队伍；同一指导教师可指导不超过 3 支队伍
赛队名称应体现专业性与创新性，不得包含商业广告、政治敏感或不雅词汇

3.3 报名方式

参赛队伍登录竞赛公众号填写报名表、上传参赛承诺书（PDF 签字版），即视为报名成功。报名表需详细填写：队伍名称、成员信息、指导教师信息、初步赛题方向意向。

报名时间：7 月 6 日至 8 月 15 日，各参赛高校组织学生线上报名参赛。以每支参赛队伍为单位扫描下方二维码填写报名信息，并按照要求上传相关证明材料（校园卡或加盖学校公章的学生证照片；因转专业导致证件上专业不符的，需由所在学院出具盖章证明）。

第四章 赛题方向与命题设计

4.1 四大赛题方向

竞赛设置四个并行赛题方向，参赛队伍报名时选定一个方向，决赛阶段分赛道评审。

🔍 方向一：智能审计赛道

围绕注册会计师审计、内部审计、审计监管等场景。推荐题目：上市公司年报风险识别智能体、关联交易穿透审计智能体、合同条款异常审计智能体、工作底稿智能复核智能体等。

💰 方向二：智能财务赛道

围绕企业财务核算、报表编制、税务筹划、预算管理等场景。推荐题目：自动凭证生成与复核智能体、合并报表智能编制助手、增值税涉税合规智能体、预算执行偏差分析智能体等。

📈 方向三：智能投研赛道

围绕证券分析、估值建模、ESG 评级、并购尽调等场景。推荐题目：DCF 估值自动建模智能体、行业研究报告智能撰写工具、ESG 报告抓取与评级智能体、并购标的尽职调查智能体等。

📚 方向四：智能教育与研究赛道

围绕会计教学、学术研究、政策研读等场景。推荐题目：CPA 考试智能题库与答疑助手、会计准则差异对比智能体、学术论文文献综述生成助手、企业AI生成式披露检测智能体等。

4.2 命题原则

无论参赛队伍选择推荐题目还是自命题，作品需满足以下三项约束：

  1. 必须使用至少一个大语言模型作为核心推理引擎（建议使用国产模型）。
  2. 必须输出结构化结果（JSON / 表格 / pdf 报告），不接受纯自然语言对话作为最终成果。
  3. 必须提供可演示原型（Web 界面或命令行均可），评审现场需能实时处理样例数据。

4.3 数据集与样例

参赛队员可自行互联网查询以下数据资源：

  • 巨潮资讯网上市公司年报 PDF。
  • 证监会近五年行政处罚决定书。
  • 上交所、深交所近五年问询函。
  • 中国会计准则、审计准则、税收法规电子版（截至比赛公告日）。

鼓励参赛队伍在官方数据集基础上，自行补充行业数据、研报、新闻、宏观经济指标等，形成具有差异化优势的知识库。所有补充数据需在最终提交时附上来源说明，确保合规合法。

第五章 赛事流程与时间节点

5.1 四阶段流程

竞赛历时约 4 个月，分为报名、初赛、决赛四个阶段。

阶段时间核心活动
报名启动2026.07.06 — 08.15竞赛宣讲、官网发布赛题、参赛队伍组队报名、缴费
初赛阶段2026.09.01 — 09.25提交《项目方案书》(PDF) + 5 分钟介绍视频，评委盲审
初赛评审2026.09.25 — 09.30对初赛的队伍开发原型，提交代码 + 演示视频 + 技术报告进行评审
决赛答辩2026.10.01 — 10.31入选决赛的队伍自行备赛，线下决赛时间另行通知
颁奖典礼决赛当晚颁奖、获奖作品展示、产业对接洽谈会

5.2 淘汰与晋级机制

  • 初赛 → 决赛：每赛道按原型评分排名，取前 20 支队伍进入决赛答辩。
  • 决赛：共 20 支队伍现场答辩，决出特等奖1个、一等奖2个、二等奖5个，三等奖12个、优秀个人奖8名，优秀指导老师20名，优秀组织奖10个。

第六章 提交物规范与技术要求

6.1 各阶段提交物清单

阶段提交物规格要求
初赛项目方案书PDF 格式，10-15 页，含问题定义、智能体架构图、数据来源、技术方案、预期成果、团队分工
初赛介绍视频MP4 格式，5 分钟以内，1080P 以上，包含队员出镜介绍 + 方案陈述
决赛答辩 PPTPPTX 格式，20 张以内，建议保留 8-10 张用于核心演示截图
决赛现场演示本机或云端均可，需保证现场网络稳定下可顺畅运行，备用录屏视频
决赛原型部署（如有）建议提供公网可访问的演示链接（评委可在赛前自行体验）

6.2 技术规范要求

6.2.1 代码规范

  • 主编程语言为 Python（≥ 3.10），允许辅以 JavaScript / TypeScript 用于前端，允许 AI 辅助编程 (Claude code；Vibe coding等工具调用)。
  • 代码必须包含完整的 requirements.txt 或 pyproject.toml，确保评委能一键复现环境。
  • 禁止在代码中硬编码 API Key 等敏感信息，应使用 .env 加载并提供 .env.example 模板。
  • 关键算法和非平凡逻辑必须包含中文注释（最低占代码量 10%）。

6.2.2 模型与算力要求

  • 建议使用国产大模型，包括但不限于：DeepSeek、通义千问、文心一言等。
  • 组委会为每支晋级决赛的队伍提供一定额度的模型 API 额度（DeepSeek + Moonshot 选其一）。
  • 禁止使用未经许可的爬取数据；外部数据需附来源声明及合规说明。

6.2.3 伦理与合规

  • 禁止使用涉密信息。
  • 智能体输出中必须包含「AI 生成」声明，避免误导使用者认为是专业意见。
  • 作品应避免对特定上市公司、个人作出未经核实的负面评价。

第七章 评审办法与评分标准

7.1 评分维度（百分制）

维度权重评分细则
专业深度25 分对会计/审计/财务专业概念的理解准确度、对真实业务流程的还原度、对监管法规的引用准确性
技术创新25 分智能体架构设计的新颖性、多智能体协作机制的精巧度、对前沿技术（RAG、辩论、思维链等）的运用
落地可行20 分原型完整度、能否处理真实数据、用户界面友好度、对接现有业务系统的潜在难度
效果评估15 分是否提供量化评估、回归测试集覆盖度、与基线方案的对比结果、性能指标的合理性
文档与展示10 分技术报告的清晰度、代码注释完整度、演示视频质量、答辩表达能力
伦理与合规5 分数据来源合规性、AI 输出的可解释性、风险提示与免责声明的完备程度

7.2 评分流程

  • 初赛与复赛：每件作品由 5 名评委独立打分。
  • 决赛：每支队伍由 7 名评委独立打分。

第十一章 知识产权与赛事纪律

11.1 知识产权归属

作品原创性知识产权（含著作权、专利申请权）默认归属于参赛队伍全体成员。组委会享有：(1) 对获奖作品在学院刊物、官网、宣传材料中的非商业性使用权；(2) 优先与作品团队进行商业化合作洽谈的权利（不构成强制约束）。

11.2 开源与数据合规

  • 参赛作品如使用开源代码或第三方组件，必须遵守相应开源协议（MIT / Apache / GPL 等）。
  • 作品中使用的所有训练 / 检索数据，必须来源合法。组委会保留数据合规审查的权利。
  • 禁止抄袭、剽窃他人作品。一经发现，立即取消参赛资格并通报参赛者所在学校。

11.3 赛事纪律

禁止行为雇佣他人代写、伪造测试数据、贿赂评委、串通其他队伍、虚假身份报名
处罚措施警告 / 取消单赛段成绩 / 取消参赛资格 / 通报所在学校 / 五年内禁赛
保密义务评审期间评委不得向第三方泄露作品细节；获奖前作品技术细节保密
