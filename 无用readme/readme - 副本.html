👶 傻瓜式一键启动教程

有手就行，学不会你来打我！
（请严格按照顺序，一步步往下点）

🛠️ 准备工作（先去下载三个东西）

在开始之前，你需要给电脑装三个“基础零件”，缺一不可：

  1. 装 Python（AI 的大脑）： 去 Python 官网 下载并安装。
    ⚠️ 致命警告：安装界面最下方，有一个叫 Add Python to PATH 的勾选项，必须打勾！必须打勾！必须打勾！（不勾的话，后面全报错，神仙也救不了你）
  2. 装 C++ 运行库（防画图崩溃）： 点击 这里下载，下载后双击，一路点“下一步”装完就行。
  3. 办一张 AI 的“饭卡”（API Key）： 去 DeepSeek 官网 注册个账号，在左侧菜单找到“API Keys”，创建并复制一串以 sk- 开头的密码，保存到记事本里备用。

🟢 第一步：召唤“黑框框”（打开终端）

我们要给电脑下达指令，得先找到输入指令的地方：

  1. 打开你下载的 项目文件夹（就是里面有一堆代码和 start.ps1 的那个文件夹）。
  2. 看文件夹最上方，有一个显示当前路径的 地址栏（比如显示着 此电脑 > D盘 > 项目）。
  3. 用鼠标点一下那个地址栏，把里面的字全删掉，然后输入 powershell 这 10 个英文字母。
  4. 按下键盘上的 回车键 (Enter)。
💡 神奇的事情发生了：一个蓝底白字或黑底白字的“黑框框”弹出来了！这就是我们的控制台。

🟡 第二步：复制粘贴“魔法咒语”

🚨 新手铁律：下面的每一段代码，请务必点击代码框右上角绿色的【📋 复制代码】按钮！
千万千万别自己用鼠标去框选复制，多复制一个空格都会导致报错！

1 解除电脑的安全封印

电脑默认不让运行脚本，我们要给它松绑。复制下面这段，在黑框框里右键粘贴，按回车。

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

（如果弹出红字问你确不确定，输入 Y 然后按回车。没弹红字就直接往下走。）

2 安装“火箭加速器”

复制下面这段，按回车。这会安装一个超快的下载工具。

pip install uv -i https://pypi.tuna.tsinghua.edu.cn/simple
🛑 停！高能预警！
上面这行跑完之后，请把这个“黑框框”关掉（点右上角 X）！
然后回到【第一步】，重新打开一个新的黑框框！
（如果不重新开，电脑会不认识刚装好的工具，直接报错。）

（现在，你应该是刚打开了一个全新的黑框框，我们继续往下）

3 修复乱码 & 填入你的“饭卡”

复制下面这一大段代码，按回车。它会自动帮你修复中文乱码，并弹出一个记事本。

# 修复 Windows 老眼昏花看不清中文的问题
$f = '.\start.ps1'; $c = [System.IO.File]::ReadAllText((Resolve-Path $f).Path, [System.Text.Encoding]::UTF8); [System.IO.File]::WriteAllText((Resolve-Path $f).Path, $c, [System.Text.UTF8Encoding]::new($true))

# 自动生成配置文件，并用记事本打开它
copy .env.example .env
notepad .env
📝 记事本弹出来了！请按照下面 3 步操作：
1. 找到 OPENAI_API_KEY=sk-your-deepseek-api-key-here 这一行。
2. 把等号后面的假密码删掉，换成你在准备工作里复制的真实“饭卡”密码。
3. 按键盘的 Ctrl + S 保存，然后关掉这个记事本。

4 一键安装，准备起飞！

最后一步！复制下面这两行，按回车。第一次跑需要下载很多东西，大概等 1~3 分钟，别急。

# 下载 AI 干活需要的所有工具箱
uv sync

# 启动系统！跑完后会自动弹出浏览器网页！
.\start.ps1
🎉 大功告成！如果浏览器自动弹出了一个很好看的深色网页，说明你彻底成功了！

☕ 以后每天怎么用？（3秒开机）

装完第一次后，以后再也不用搞上面那些复杂的步骤了！

日常使用只需 2 步：
1. 打开项目文件夹，在地址栏输入 powershell 回车，打开黑框框。
2. 复制下面这句“极速启动咒语”并回车： 
.\start.ps1 -SkipSync

🆘 救命稻草（如果报错了看这里）

❓ 报错提示：uv 不是内部或外部命令
大白话翻译：你装完加速器后，没有重新开黑框框！
怎么救：把黑框框关了，重新按【第一步】打开，再跑后面的代码。
❓ 网页提示：Network Error 或者 AI 说话说一半断了
大白话翻译：你的“饭卡”（API Key）填错了、没钱了，或者没保存！
怎么救：在黑框框里输入 notepad .env 回车，重新检查密码对不对，保存后关掉。然后在黑框框里按 Ctrl + C 停掉程序，重新运行启动命令。
❓ 报错提示：端口 5000 被占用
大白话翻译：你电脑里已经有别的程序占了 5000 这个位置。
怎么救：把启动命令换成 .\start.ps1 -Port 8080，然后自己打开浏览器，输入 http://localhost:8080 访问。
❓ 报错提示：DLL load failed 或者画图时崩溃
大白话翻译：你准备工作里的“C++ 运行库”没装！
怎么救：去准备工作第 2 步，把那个运行库下载安装一下，然后重启电脑。
