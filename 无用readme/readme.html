🚀 小白专属：复制粘贴即用指南

不要管任何复杂的原理，只需要按照以下步骤，点击代码块右上角的 “复制代码” 按钮，粘贴到终端回车即可。

🛠️ 准备工作（必须手动做）

  1. 去 Python 官网 下载安装 Python 3.12 或以上版本。
    ⚠️ 致命坑预警：安装时务必勾选底部的 Add Python to PATH（添加到环境变量），否则后续全报错！
  2. 下载安装 Visual C++ 运行库（一路下一步即可，装过可跳过）。（注：不装这个，后续画图会直接崩溃）
  3. 去 DeepSeek 开放平台 注册账号，获取你的 API Key（以 sk- 开头）。

🟢 第一步：用“秘籍”打开项目终端

  1. 打开你下载的项目文件夹（就是包含 start.ps1 和 src 文件夹的那个目录）。
  2. 在文件夹顶部的 路径地址栏 里，清空里面的内容，输入 powershell 然后按 回车。
💡 技巧：这会直接在这个文件夹里打开命令行窗口，完美避开小白最头疼的“找不到路径”问题！

🟡 第二步：复制粘贴以下命令（请逐段运行）

1. 打通 Windows 系统的“任督二脉”

# 允许 PowerShell 运行本地脚本
# （如果弹出红字提示，请输入 Y 并回车）
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

2. 安装极速包管理器 uv

# 使用国内清华镜像安装 uv（防止官方网络被墙，几秒钟就能装完）
pip install uv -i https://pypi.tuna.tsinghua.edu.cn/simple
🚨 高能预警（新手必看）：
运行完上面这行后，请务必关闭当前的 PowerShell 窗口！
然后重复“第一步”的操作，重新打开一个新的 PowerShell 窗口，再继续往下复制！（这是为了让系统认识刚装好的 uv 命令，不重启会报错找不到 uv）。

（在新的 PowerShell 窗口中继续复制）

3. 修复启动脚本 & 配置 AI 门禁卡

# ==========================================
# 3. 修复启动脚本的“隐形乱码坑”
# ==========================================

# 【防坑魔法】修复 Windows PowerShell 5.1 读中文乱码的问题
# （必须使用 $true 强制带 BOM 签名，直接复制运行即可）
$f = '.\start.ps1'; $c = [System.IO.File]::ReadAllText((Resolve-Path $f).Path, [System.Text.Encoding]::UTF8); [System.IO.File]::WriteAllText((Resolve-Path $f).Path, $c, [System.Text.UTF8Encoding]::new($true))


# ==========================================
# 4. 配置 AI 的“门禁卡” (API Key)
# ==========================================

# 复制一份环境变量模板，生成你自己的配置文件
copy .env.example .env

# 用记事本打开配置文件
notepad .env
🚨 注意：运行 notepad .env 后，会弹出一个记事本窗口。
1. 找到 OPENAI_API_KEY=sk-your-deepseek-api-key-here 这一行。
2. 把等号后面换成你自己的真实 API Key。
3. ⚠️ 致命坑预警：文件里只能保留一个 OPENAI_API_KEY！请把其他带 # 注释掉的备用假 Key 删掉。
4. 按 Ctrl + S 保存，然后关闭记事本。

5. 一键安装依赖并起飞！

# ==========================================
# 5. 自动创建环境、安装依赖并启动
# ==========================================

# 自动下载并安装项目需要的所有 AI 依赖包
# （首次运行需要 1~3 分钟，请耐心等待）
uv sync

# 启动系统！（运行后会自动弹出浏览器，开始享受 AI 审计吧！）
.\start.ps1

☕ 日常使用（第二次及以后怎么打开？）

🎉 以后每次使用：
不需要再安装任何东西！只需要在项目文件夹地址栏输入 powershell 回车，然后运行下面这行命令即可 3秒极速启动： 
.\start.ps1 -SkipSync

📚 如何投喂自己的法规/案例？

把 UTF-8 编码的 .txt 文件（比如最新的审计准则、处罚案例）直接丢进项目里的 knowledge_base/ 文件夹。
然后在网页左侧状态栏点击 🔄 重载知识库（或重启服务），AI 就能立刻学会你投喂的新知识，回答更有理有据！

❓ 遇到报错怎么办？（对号入座）

报错：uv 不是内部或外部命令
原因：说明你第二步装完 uv 后，没有重启 PowerShell 窗口。
解决：关掉黑框，重新在文件夹地址栏输入 powershell 进终端，从第 3 步开始继续。
网页提示 Network Error 或后端突然中断
原因：你的 API Key 填错了、没余额了，或者 .env 里留了多个 Key 导致冲突。
解决：在终端重新运行 notepad .env，仔细检查 Key 是否正确，保存后按 Ctrl+C 停掉服务，再重新运行 .\start.ps1。
报错：DLL load failed 或画图崩溃
原因：你的 Windows 缺少 C++ 运行库。
解决：去准备工作里下载并安装 Visual C++ 运行库，重启电脑。
报错：端口 5000 被占用
解决：把启动命令换成 .\start.ps1 -Port 8080，然后浏览器手动访问 http://localhost:8080。
