🔧 一、环境要求与准备

在开始部署之前，请确保你的计算机满足以下最低要求：

① 操作系统

Windows 10/11（64位）。macOS / Linux 用户可参考手动流程（PowerShell 脚本为 Windows 优化）。

② Python 3.12

项目依赖 Python 3.10 及以上版本，推荐使用 Python 3.12。

⚠️ 重要：安装时请务必勾选底部 "Add Python to PATH"， 否则后续命令将无法识别。

下载地址：python.org/downloads

项目目录已附带安装包 python-3.12.10-amd64.exe，可直接双击安装。

③ Visual C++ 运行库

部分 Python 包（如 chroma-hnswlib）依赖 VC++ 编译运行时。

项目目录已附带 VC_redist.x64.exe，双击并按提示完成安装即可。

💡 如果之前安装过 Visual Studio / C++ 开发工具，通常已包含该运行库，可跳过此步骤。

④ uv 包管理器

uv 是 Rust 编写的超快速 Python 包管理器，比 pip 快 10-100 倍。项目使用 uv 管理依赖。

安装命令（在终端中执行）：

# 方式一：PowerShell 一键安装
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# 方式二：pip 安装
pip install uv

# 验证安装
uv --version

⑤ DeepSeek API Key（核心）

系统需要调用 LLM 进行审计风险分析，需注册 DeepSeek 开放平台获取 API Key。

  1. 访问 platform.deepseek.com 注册
  2. 在控制台创建 API Key（以 sk- 开头）
  3. 复制备用——后续配置 .env 文件时需要填入
📌 注意：如果没有 API Key，系统仍可启动 Web 界面，但发送分析请求时会报 LLM 连接错误。 竞赛评委可提前申请测试 Key 进行演示。

🚀 二、一键启动流程

系统提供两种启动方式：零门槛一键启动 和 手动逐步骤部署。

方式一：极速启动（推荐）

适合首次使用的用户，双击批处理文件即可完成全部部署。

首次部署（仅需一次）

  1. 双击运行 前置库安装.bat
    → 自动检测 Python、安装 uv、创建虚拟环境、下载全部依赖
  2. 自动弹出记事本编辑 .env 文件
    → 将 OPENAI_API_KEY=... 改为你的 真实 API Key
    → Ctrl+S 保存关闭 → 回到命令行按任意键继续
  3. 等待浏览器自动打开 http://localhost:5000

日常启动

双击 启动.bat → 浏览器自动弹出 → 开始使用

方式二：PowerShell 脚本启动

适合开发者或需要自定义参数的场景。

# 默认启动（Web 模式 + 自动打开浏览器 + 端口 5000）
.\start.ps1

# 指定端口（避免端口冲突）
.\start.ps1 -Port 8080

# 仅启动 HTTP 服务（不打开浏览器）
.\start.ps1 -Mode http -Port 5000

# 跳过依赖同步和知识库检查（已部署过时快速启动）
.\start.ps1 -SkipSync -SkipKB

参数说明

参数默认值说明
-Modeweb运行模式：web（界面+服务）、http（仅服务）、flow（CLI 完整流程）、node（单节点）
-Port5000HTTP 服务端口
-SkipSync-跳过 uv sync 依赖安装（已装过时加速）
-SkipKB-跳过知识库检查
-NoBrowser-不自动打开浏览器

方式三：手动逐步骤部署

适合了解每一步具体在做什么的开发者或竞赛评委复现。

#步骤命令说明
1 安装 uv pip install uv 若已安装可跳过
2 配置环境变量 copy .env.example .env 编辑 .env 填入 API Key
3 安装依赖 uv sync 基于 pyproject.toml 同步
4 初始化知识库 （自动） 首次检索时自动加载
5 启动 HTTP 服务 uv run python src/main.py -m http -p 5000 浏览器打开 localhost:5000 
# 完整手动部署命令（PowerShell 逐行执行）
pip install uv
copy .env.example .env
# ↑ 然后编辑 .env 填入真实的 OPENAI_API_KEY
uv sync
uv run python src/main.py -m http -p 5000
💡 启动后访问：浏览器打开 http://localhost:5000， 你将看到深色主题的 Web 控制台。左侧状态栏显示系统各组件健康状况。

🧩 三、五大功能模块

系统提供五个核心审计分析模块，在 Web 界面的欢迎页以快捷按钮呈现，点击后弹出二选一弹窗（上传文件 / 手动输入数据）。

📊
财务指标分析
自动计算 16 项关键财务比率（资产负债率、流动比率、存贷双高、商誉占比等），识别异常指标并生成可视化图表。
📝
披露规范性检查
对照信披管理办法第 22 条等法规，检查年报 7 项必要章节、5 项关键披露是否完整，输出合规评分。
🎯
综合风险评估
全方位审计风险分析：财务指标（50%）+ 披露合规（30%）+ 数据校验（20%），输出 0-100 综合评分与风险等级。
📦
批量上传年报
同时上传多份年报 PDF/Word/Excel，系统逐份独立分析，生成独立报告，支持线程池并行处理。
⚖️
监管处罚检索
检索证监会处罚函、问询函、警示函等监管信息，基于本地知识库 RAG 检索，进行相似案例对照。

📄 报告导出

分析完成后，系统自动生成可下载的审计报告文件：

  • PDF 风险报告：包含目录页、风险总览摘要、五维度风险分布表、风险逐项说明、免责声明页
  • Excel 审计底稿：结构化工时底稿，包含财务指标、校验结果、风险清单等Sheet
  • 可视化图表：风险热力图、财务雷达图、多年趋势图（PNG 格式，可下载）

⚡ Flash 快速模式

点击顶部栏 ⚡ 快速 按钮启用。启用后跳过图表生成与多智能体辩论复核、法规检索合并为一次、仅输出前 3 条核心风险，目标响应时间 1 分钟以内，适用于快速预览和压力测试。普通模式为完整链路（热力图/雷达图 + 三方辩论复核 + 完整风险明细），目标 3 分钟以内；正式报告建议使用普通模式。PDF/Excel 报告两种模式下均由系统自动兜底导出。

🧠 多智能体辩论机制

系统内置三方辩论制衡（默认开启，快速模式下跳过）：

  1. 风险关注方：识别并主张存在风险
  2. 风险否定方：质疑风险识别结果，防止误判
  3. 裁判仲裁：综合两方意见，给出最终裁定

辩论结果以折叠面板形式呈现在分析报告末尾。

🔐 多用户登录与分析历史

侧边栏「账户」区点击 🔐 登录 / 注册：注册后自动登录，每次分析完成会自动保存到你的专属历史（公司名称、综合评分、风险等级、分析模式、报告/图表下载链接），点击 📜 历史分析 随时回溯。

  • 数据隔离：历史按账户严格隔离，不同用户互不可见；口令以 PBKDF2 加盐哈希存储，不存明文
  • 游客模式：不登录也可正常分析（演示零门槛），仅不保存历史
  • 存储位置：默认项目目录下 local_data.db（SQLite），配置 PGDATABASE_URL 可切 PostgreSQL

❓ 五、常见问题与故障排除

Q1: PowerShell 执行报错 "&& 是无效的语句分隔符"

Windows PowerShell 不支持 && 连接多条命令。请改用 ;（分号）分隔。

# ❌ 错误
cd project && uv sync

# ✅ 正确
cd project; uv sync

Q2: 启动后页面全是 ❌ 状态（服务频繁重启）

这是 uvicorn 热重载机制导致的问题。当 app.log 写入日志时触发热重载 → 重启后再次写日志 → 死循环。

解决方法：确保启动命令中包含 reload 白名单配置（v4.0 版本已默认修复）。

💡 如果仍遇到此问题，请在 src/main.py 中确认 uvicorn.run() 包含 reload_includes=["*.py"] 参数。

Q3: 端口被占用

# 检查 5000 端口占用
netstat -ano | findstr :5000

# 使用其他端口启动
.\start.ps1 -Port 8080

Q4: 知识库加载失败

知识库文件位于 knowledge_base/ 目录。确保目录下至少有一个 .txt 文件。

如果知识库状态显示「未就绪」，可尝试：

  1. 点击左侧栏底部的 🔄 重载知识库 按钮
  2. 或通过 📥 添加知识库 按钮上传额外的法规文件（支持 PDF/Word/Excel/TXT 等格式）

Q5: 中文字体导致 PDF/图表中文显示异常

确保 assets/wqy-microhei.ttc 字体文件存在。如果缺失，PDF 导出和图表中的中文可能显示为方框。

可从文泉驿官网下载 wqy-microhei.ttc 放入 assets/ 目录。

Q6: ModuleNotFoundError / 依赖缺失

重新运行依赖同步：

uv sync

如果 uv sync 失败，检查网络连接或尝试：

uv sync --reinstall

Q7: uv 命令找不到

uv 安装后需要重启终端或手动添加 PATH。PowerShell 中执行：

$env:Path = [System.Environment]::GetEnvironmentVariable("Path","Machine") + ";" + [System.Environment]::GetEnvironmentVariable("Path","User")
uv --version

Q8: Python 中文路径读取失败

如果项目路径包含中文，某些工具可能出错。建议将项目放在纯英文路径下（如 D:\projects\audit）。
